### 🚗 Функциональное тестирование веб-приложения «Яндекс.Маршруты» (Расчет поездки на авто)

> **О проекте:**  
> **«Яндекс.Маршруты»** - веб-сервис для планирования передвижения по городу, позволяющий прокладывать оптимальные маршруты и рассчитывать время и стоимость поездки для различных видов транспорта.

`Web Testing` `Functional Testing` `Test Design` `Test Cases` `Boundary Value Analysis` `Equivalence Partitioning` `Bug Reporting`

* **Тестирование форм и бизнес-логики (68 тест-кейсов):**  
  Составила 68 тест-кейсов и провела функциональное тестирование валидации полей ввода времени и адресов в форме, а также логики расчета стоимости и времени поездки на собственном автомобиле.  
  * **Результат:** Исключила возможность отправки некорректных данных и обеспечила точность калькуляции маршрута для пользователя.

* **Работа с дефектами (16 багов):**  
  Локализовала и зафиксировала 16 дефектов, оформив подробные баг-репорты с шагами воспроизведения.  
  * **Результат:** Предотвратила сбои интерфейса при вводе граничных значений и повысила общую надежность сервиса.
